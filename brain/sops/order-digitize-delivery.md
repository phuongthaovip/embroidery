# SOP — Có đơn → digitize → giao file qua email

> Chủ: **CS** (tới khi có bot CS: CEO giao). Cập nhật 2026-11-21. Nhiều bước còn `[?]` — cần anh Nam xác nhận.
> Nguồn: [`CLAUDE.md`](../../CLAUDE.md) §3, [`00-context/shop-profile.md`](../../00-context/shop-profile.md), [`00-context/2026-11-19-shopify-policies.md`](../../00-context/2026-11-19-shopify-policies.md).

⚠️ 2026-11-21: EmbroThread **chưa nhận được thanh toán** → chưa có đơn Shopify. Etsy có đơn thật.

1. **Nhận đơn**: Etsy (mail "You made a sale!") hoặc Shopify (Admin → Orders). Ghi mã đơn, mã card/SKU (`VPE…`/`EMBN…`), định dạng khách cần.
2. **Giao digitize**: gửi designer (board Designer Online - Nguyen Hop?) mockup + size (4–7") + 8 định dạng mặc định CSD, DST, EXP, HUS, JEF, PES, PCS, VP3. Ai nhận, kênh nào `[?]`.
3. **QA file**: mở được, đủ size/định dạng, giống mockup, test thêu nếu có `[?]`.
4. **Giao file trong 1–3 ngày làm việc** qua email trên đơn (Shopify: email checkout). Hộp gửi `[?]` (policy ghi business@embrothread.com cho hỗ trợ). Nhắc khách xem spam.
5. File đã có sẵn → có thể dùng app **Digital Products** (giao ngay khi mua) cho lần bán sau.
6. **Lỗi file** → sửa/gửi lại; không sửa được → hoàn tiền (Refund policy). Đổi ý trước khi gửi → huỷ + hoàn.
7. Ghi đơn + thời gian giao vào [[brain/metrics/README]] (tuần) `[?]` file theo dõi đơn.
