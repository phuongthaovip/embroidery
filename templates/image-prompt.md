# Prompt gen ảnh AI (ChatGPT / Gavana)

Mục tiêu: ảnh mockup trông như **file thêu máy thật** và designer **digitize được giống ảnh**.

## Đuôi prompt chuẩn (luôn gắn vào cuối)
```
Style: machine embroidery design mockup, realistic satin and fill stitch texture,
flat colors only (max 6 thread colors), bold clean outlines, no gradients, no shading,
no tiny details or thin lines, no photo-realism, simple shapes that can be digitized,
centered on plain white background, fits a 4x4 inch hoop, square 1:1 image.
```

## Mẫu cho design lẻ
```
A [SUBJECT + ACTION/POSE], [STYLE KEYWORD: preppy / coquette / cottagecore / funny / vintage],
[COLOR PALETTE: e.g. pink, mint, navy, red], [TEXT nếu có: the words "..." in bold rounded letters].
+ đuôi prompt chuẩn
```

## Mẫu cho bundle (≤ 20 mẫu)
```
A set of [N] separate small embroidery designs arranged in a neat [3x3 / 4x4] grid,
each design isolated with white space around it, consistent style and palette:
[liệt kê từng mẫu: 1) ..., 2) ..., 3) ...].
+ đuôi prompt chuẩn
```

## Mẫu cho ITH (in-the-hoop) / applique
```
In-the-hoop applique embroidery design of a [SHAPE: scallop bag tag / pennant / bag tie],
visible applique fabric with satin stitch border, [THEME ICON] in the center,
[blank name area nếu có], + đuôi prompt chuẩn
```

## Quy tắc
- Chữ trong ảnh: tối đa ~6 từ, font to, dày. AI hay viết sai chính tả → kiểm tra trước khi list.
- Không dùng nhân vật, logo, thương hiệu, đội thể thao có bản quyền.
- Bundle: các mẫu cùng palette và cùng nét vẽ để nhìn đồng bộ.
