# Idea Card — mẫu

Copy block dưới vào `02-ideas/backlog.md` cho mỗi idea.

```
### [ID] Tên idea
- Ngày: YYYY-MM-DD
- Niche / dịp: (vd: Halloween, nurse, dog mom, Christmas…)
- Mô tả ngắn: 1–2 câu hình dung design
- Keyword chính: (tiếng Anh)
- Bằng chứng nhu cầu: (nguồn + số liệu + ngày lấy)
- Mức cạnh tranh: Thấp / TB / Cao (nguồn)
- Thời điểm: evergreen / mùa vụ (cần list trước ngày …)
- Khả thi kỹ thuật: khung, số màu, kỹ thuật thêu
- Rủi ro IP: Không / ⚠️ (ghi lý do)
- Điểm: Nhu cầu _/5 · Cạnh tranh _/5 · Khả thi _/5 · Hợp shop _/5 = __/20
- Trạng thái: new / chọn / brief / đang làm / đã list / loại
```

## Tiêu chí chấm điểm (nháp — sẽ chỉnh cùng anh)
- **Nhu cầu (5 = cao):** lượt tìm / số bán của listing tương tự
- **Cạnh tranh (5 = ít đối thủ):** số listing, chất lượng đối thủ
- **Khả thi (5 = dễ làm):** thời gian làm, độ khó thêu
- **Hợp shop (5 = rất hợp):** đúng niche, style, khách hàng hiện có
